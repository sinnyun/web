方法 2：使用 Vercel 的重定向规则 (vercel.json)

这种方法更灵活，不需要修改你的 index.html 文件，而是通过 Vercel 的配置文件来控制访问。

创建 vercel.json 文件（如果还没有）：

在你的项目根目录下创建一个名为 vercel.json 的文件。
添加重定向规则：

在 vercel.json 文件中添加以下内容：

<JSON>
{
  "rewrites": [
    {
      "source": "/",
      "destination": "/404.html"
    }
  ]
}
确保你的项目根目录下存在 404.html 文件（与方法 1 相同）。

提交和推送：

提交并推送 vercel.json 文件和 404.html 文件（如果之前没有提交）：
<BASH>
git add vercel.json 404.html
git commit -m "Temporarily redirect to 404 page using vercel.json"
git push origin main
Vercel 会读取 vercel.json 文件，并将对根路径 (/) 的所有请求重定向到 404.html 文件。

恢复主页：

要恢复主页，只需要从 vercel.json 文件中删除或注释
