明白了。如果你只需要主页跳转到404页面，并且需要一个简单的方式来切换回正常主页，可以这样做：

**方法一：修改 `vercel.json` (仅跳转主页到 404)**

这种方法最简单，直接修改 `vercel.json` 文件。

1.  **`vercel.json` 内容:**

```json
{
  "routes": [
    {
      "src": "^/$",
      "dest": "/404.html",
      "status": 404 //可选，但建议添加
    }
  ]
}
```

**解释:**

*   **`src: "^/$"`**:  只匹配根路径 `/`。 `^` 表示字符串的开头，`$` 表示字符串的结尾，因此只匹配空路径，即主页。
*   **`dest: "/404.html"`**: 将对根路径的请求路由到 `404.html`。
*   **`status: 404` (可选，但建议添加)**: 添加这个可以显式指定响应状态码为404，虽然目标文件是404.html，但如果没有这个 status，可能返回200，对于SEO不利。

2.  **部署到 Vercel:** 保存 `vercel.json` 并将其推送到你的 Vercel 仓库。Vercel 会自动部署更改。

3.  **切换回正常主页:**  当你想要恢复正常主页时，只需要修改 `vercel.json`，将其内容修改为以下内容，然后重新部署：

```json
{
  "routes": [
    {
      "src": "^/$",
      "dest": "/index.html"
    }
  ]
}
```

或者，如果你想让所有的请求都正确路由 (包括子页面):

```json
{
  "routes": [
    {
      "src": "^/$",
      "dest": "/index.html"
    },
    {
      "src": "/(.*)",
